## Budget

**Test phase (Days 1-5):** R500/day = R2,500 total
- 3 ad creatives × 3 audience segments = 9 combos
- ~R55 per combo = enough to learn CPC and CTR

**Scale phase (Days 6-30):** R2,000/day = R60,000/month
- Only if test-phase CAC < R750 per WhatsApp lead
- If CAC > R750: pause and iterate creative

**Success metrics:**
- CPC < R15
- WhatsApp message rate > 3%
- Lead-to-sale conversion > 8%
- Target CAC: < R750/lead, target CPA (paid sale): < R2,500
- Payback period: < 30 days (single R2,599 payment = paid back)
